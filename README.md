प्यारे अजगर प्रोग्राममर्स,

मैंने अजगर इसलिए बनाया था की आप सभी प्रोग्राम करपाओ,

आजगर की खासियत ही ये है की कोई भी वो हिन्दी मे लिखके प्रोग्राम करसक्त है,

परंतु कोई भी चीज को करने से पहले उससे अच्छे से सीखना होता है।

मैंने ये रीपाज़टॉरी इसलिए बनाई है की, आप सभी अजगर मे प्रोग्राम करना सीख पाओ।

इस रीपाज़टॉरी मे कुछ पाठ दिए गए है जिनसे आप अच्छे से अजगर प्रोग्राम करना सीख स हो। 

एक बार यहाँ से सारे पाठ को सीखलिया, तो आप जी भ के अजगर प्रोग्राम करना।
